# ArchFlow // PRO (BIM-Fintech)

Portal de Especificação Viva, Congelamento de Escopo e Liquidação via Pix Split para Arquitetura de Alto Padrão.

## Visão Geral

O **ArchFlow // PRO** une renderização arquitetônica em tempo real com governança financeira e split automático de pagamento:

1. **Front-End Reativo:** Alternância interativa de acabamentos (Ouro, Prata, Essencial) em superfícies BIM (Ilha Gourmet, Piso Principal, Marcenaria), com recálculo orçamentário instantâneo.
2. **Raio-X do Arquiteto (RT):** Visualização confidencial de Reserva Técnica e repasses líquidos a fornecedores homologados.
3. **Congelamento de Escopo (Scope Lock):** Assinatura criptográfica com geração de hash SHA-256 para blindagem jurídica contra retrabalho.
4. **Motor Pix Split D+0:** Geração de payload Pix e simulação de webhook bancário SPI com liquidação atômica e comissão retida na fonte sem bitributação.

## Tecnologias

- TailwindCSS (Dark Mode / Design System Inset-Neumorphic)
- Google Fonts (Inter & JetBrains Mono)
- Lucide Icons
- Web Crypto API (SHA-256)
